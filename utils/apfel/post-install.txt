apfel uses the on-device model behind Apple Intelligence, which must
be switched on before any prompt works:

  System Settings > Apple Intelligence & Siri

It needs Apple Silicon and macOS 26 or later.

Shell completions are installed, but your shell only finds them if it
is already looking in these directories. Nothing here changes your
shell configuration.

  zsh   In ~/.zshrc, ABOVE the line that runs compinit:

          fpath=($BASE/share/zsh/site-functions $fpath)

        Adding to fpath after compinit has run does nothing at all.

  bash  Found automatically by bash-completion 2.x via XDG.

  fish  Found automatically.
